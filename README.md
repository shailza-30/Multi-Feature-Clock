# Multi-Feature-Clock

> A Python-based multi-feature clock app with digital clock, world clock, stopwatch, and timer functionalities using Tkinter.

---

## Description

**MultiFeatureClockApp** is a Python-based GUI application developed using Tkinter.
It allows users to:

- Display time in various formats (12-hour and 24-hour)
- Show a world clock with multiple time zones
- Use a stopwatch with start, stop, and reset functionality
- Set and manage a countdown timer with hours, minutes, and seconds

---

## Tech Used 

Python: Core programming language

Tkinter: GUI Components (Label, Button, Entry, Combobox, etc.)

pytz: Timezone management for world clock

time: For handling time in digital clock, stopwatch, and timer
